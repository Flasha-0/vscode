# Flasha Code 🔥

محرر كود / IDE مجاني ومفتوح المصدر، مبني للـ Vibe Coding.

**الموديل الافتراضي:** Big Pickle (مجاني)
**الوضع الافتراضي:** Auto Mode

## المميزات

- **AI مدمج** - شات + Agent + Auto Complete (يدعم 75+ موديل)
- **15 وضع ذكي** - Auto/Plan/Build/Chat/Review/Debug/Test/Document/Refactor/Security/Deploy/Analyze/Design/Migrate/Git
- **ذاكرة أوتوماتيكية** - يتعلم أسلوبك في الكود
- **قواعد أوتوماتيكية** - يحلل مشروعك ويكتب القواعد بنفسه
- **Hooks** - أتمتة الأحداث (Save, Commit, Build)
- **Live Preview** - معاينة حية مدمجة
- **Checkpoints** - حفظ/استرجاع حالات المشروع
- **GitHub تكامل** - OAuth + Clone/Push/Pull/PR
- **Supabase تكامل** - Connection Wizard + Table Viewer
- **Vercel Deploy** - زر نشر واحد
- **7 لغات** - عربي (افتراضي) + English + Español + Français + 中文 + हिन्दी + Português
- **دعم RTL** - واجهة عربية كاملة

## المتطلبات

- Node.js 22.x
- npm/yarn
- OpenCode CLI (اختياري - للـ AI features)

## البداية

```bash
git clone https://github.com/Flasha-0/vscode.git
cd vscode
yarn install
yarn compile
yarn start
```
